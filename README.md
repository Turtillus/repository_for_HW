# Проект "Банковские операции"

## Описание
Позволяет маскировать номера карт и счетов, фильтровать данные пользователей по ключу и сортировать их по дате

## Требования 
pytnon 3.13, библиотеки typing, datetime

## Установка 
Клонируйте репозиторий:
```
git clone https://github.com/Turtillus/repository_for_HW.git
```
## Использование
Модуль widget нужен для маскирования номеров карт и счетов (код сам определяет, что перед ним)
В модуле processing есть две функции. filter_by_state позволяет фильтровать значения по заданному ключу; sort_by_date сортирует список словарей по дате
